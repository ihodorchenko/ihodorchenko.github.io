# Senior iOS Developer — персональный лендинг

Статическая страница-визитка Senior iOS Developer. Без сборки, без зависимостей и без бэкенда:
чистые HTML + CSS + JS, работает прямо из файла.

## Структура

```
.
├── index.html                  # разметка (русская версия — базовый текст в HTML)
├── styles.css                  # оформление, адаптив, print-стили
├── main.js                     # английские переводы, переключатель языка, анимации
├── assets/
│   ├── igor.jpg                # портрет (1440×1920)
│   └── og.jpg                  # превью для соцсетей (1200×630)
├── .well-known/                # Universal Links / App Links (не трогать)
└── .nojekyll                   # GitHub Pages: отключить Jekyll, чтобы отдавать .well-known как есть
```

## Как открыть

Двойной клик по `index.html` — или локальный сервер:

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## Языки

По умолчанию страница на русском. Переключатель **RU / EN** в шапке меняет весь текст,
заголовок вкладки и meta-описание, а выбор запоминается в `localStorage`.
Ссылку можно шарить сразу в нужной версии: `index.html?lang=en`.

Русские тексты лежат прямо в `index.html` (так страница остаётся осмысленной без JavaScript),
английские — в объекте `EN` в начале `main.js`. Чтобы поправить перевод, меняйте только `EN`.
Чтобы поправить русский текст — правьте `index.html` в элементе с нужным `data-i18n`.

## Как обновлять

| Что | Где |
| --- | --- |
| Фото | заменить `assets/igor.jpg` (вертикальное, 4:5) |
| Опыт, проекты, текст | `index.html` |
| Ссылка на LinkedIn | в `index.html`, встречается 5 раз: шапка, мобильное меню, hero, контакты, футер |
| Английская версия | объект `EN` в `main.js` |
| Цвета, шрифты | переменные в `:root` в `styles.css` (`--accent`, `--bg`, `--sans`…) |

## Публикация

Репозиторий настроен как сайт целиком: `index.html` в корне — главная страница
GitHub Pages (`https://<user>.github.io/<repo>/`).

**Важно про `.well-known`:** файлы Universal Links / App Links лежат в `.well-known/`.
Jekyll по умолчанию пропускает папки, начинающиеся с точки, поэтому в корне лежит `.nojekyll` —
он отключает Jekyll, и `.well-known` отдаётся статикой. Не удаляйте `.nojekyll`,
иначе `apple-app-site-association` перестанет открываться.

## Технические заметки

- Адаптив: 1440 / 1024 / 820 / 390 px, проверено в headless Chromium.
- Доступность: семантические секции, `aria-*`, skip-link, видимый фокус,
  поддержка `prefers-reduced-motion`, версия без JS (через `<noscript>`).
- SEO: title, description, Open Graph и Twitter Card (`assets/og.jpg`).
- Печать в PDF: отдельные print-стили, тёмная тема заменяется на светлую.
