# Персональный лендинг Senior iOS Developer

Статическая страница-визитка: только роль, опыт и контакты — без фото, имени и персональных данных.
Без сборки, зависимостей и бэкенда: чистые HTML + CSS + JS, работает прямо из файла.

## Структура

```
.
├── index.html                  # разметка (русская версия — базовый текст в HTML)
├── styles.css                  # оформление, адаптив, print-стили
├── main.js                     # английские переводы, переключатель языка, анимации
├── assets/
│   └── og-2026.jpg                  # превью для соцсетей (1200×630)
├── .well-known/                # Universal Links / App Links (не трогать)
└── .nojekyll                   # GitHub Pages: отключить Jekyll, чтобы отдавать .well-known как есть
```

## Как открыть

Двойной клик по `index.html` — или локальный сервер:

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## Темы

Тема по умолчанию подстраивается под систему (`prefers-color-scheme`). Переключатель в шапке
(на мобильных — пункт «Тема» в меню) циклически меняет режим:

**Авто → Светлая → Тёмная → Авто**

Выбор хранится в `localStorage` (`ih-theme`). Для скриншотов и шаринга можно форсировать тему
параметром в адресе: `index.html?theme=light` или `?theme=dark`.

Светлая палитра — блок `:root[data-theme="light"]` в конце `styles.css`; там же переопределения
для карточек, обложек, панели AI и блока контактов.

## Языки

По умолчанию страница на русском. Переключатель **RU / EN** в шапке меняет весь текст,
заголовок вкладки и meta-описание, а выбор запоминается в `localStorage`.
Ссылку можно шарить сразу в нужной версии: `index.html?lang=en`.

Русские тексты лежат прямо в `index.html` (так страница остаётся осмысленной без JavaScript),
английские — в объекте `EN` в начале `main.js`. Чтобы поправить перевод, меняйте только `EN`.
Чтобы поправить русский текст — правьте `index.html` в элементе с нужным `data-i18n`.

## Кэш и версии ассетов

GitHub Pages отдаёт файлы с `cache-control: max-age=600`, а Firefox кэширует их агрессивно.
Поэтому в `index.html` к `styles.css` и `main.js` добавлен параметр версии:

```html
<link rel="stylesheet" href="styles.css?v=20261022b">
<script src="main.js?v=20261022b" defer></script>
```

**При каждом деплое меняйте `v=`** (достаточно `?v=дата`), иначе браузеры могут показать старую
версию стилей или скриптов. После смены версии пользователю достаточно обычного обновления
страницы — новые URL не берутся из кэша.

## Публикация

Репозиторий настроен как сайт целиком: `index.html` в корне — главная страница
GitHub Pages (`https://<user>.github.io/<repo>/`).

**Важно про `.well-known`:** файлы Universal Links / App Links лежат в `.well-known/`.
Jekyll по умолчанию пропускает папки, начинающиеся с точки, поэтому в корне лежит `.nojekyll` —
он отключает Jekyll, и `.well-known` отдаётся статикой. Не удаляйте `.nojekyll`,
иначе `apple-app-site-association` перестанет открываться.

## Технические заметки

- Адаптив: 1440 / 1024 / 820 / 390 px, проверено в headless Chromium.
- Доступность: семантические секции, `aria-*`, skip-link, видимый фокус,
  поддержка `prefers-reduced-motion`, версия без JS (через `<noscript>`).
- SEO: title, description, Open Graph и Twitter Card (`assets/og-2026.jpg`).
- Темы: авто/светлая/тёмная, `color-scheme`, `<meta name="theme-color">` обновляется при переключении.
- Печать в PDF: отдельные print-стили, тёмная тема заменяется на светлую.
